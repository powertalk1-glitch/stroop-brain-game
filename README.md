# 腦筋急轉色

繁體中文 Stroop 色字反應遊戲。玩家必須忽略文字與顏色之間的干擾，在 60 秒內依指令選出正確答案。

## 線上遊玩

https://powertalk1-glitch.github.io/stroop-brain-game/

## 遊戲內容

- 玩家模式：成人、兒童 6–12 歲、長輩
- 玩法：看字色、看字義、混合指令
- 難度：簡單、普通、困難
- 共 27 種玩法組合
- 速度分、連擊加分、音效與震動回饋
- 切換 App 時自動暫停，返回後倒數繼續
- 不登入、不追蹤、不儲存個人資料或遊戲紀錄

> 本遊戲僅供娛樂與腦力挑戰用途，並非醫療或認知診斷工具。

## 本機執行

直接開啟 `index.html`，或在專案目錄啟動靜態伺服器：

```bash
python -m http.server 4173
```

## 測試

```bash
npm install
npm run check
npm run test:e2e
```

`test:e2e` 會檢查桌面與手機版流程、答題、暫停續玩、60 秒結算及水平溢出。
